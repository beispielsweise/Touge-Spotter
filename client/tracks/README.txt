TougeSpotter road recordings.

One file per track, named <trackID>.txt (e.g. pk_akina.txt), each a list of
"x y z" world positions in driving order, recorded top-to-bottom.

Recorded files are written here if the folder is writable (normal behavior); otherwise they go to
Documents/Assetto Corsa/TougeSpotter/ and can be copied here by hand. 

Files are always read from here first.
